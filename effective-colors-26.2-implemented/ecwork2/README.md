# Effective Colors

Minecraft Java 26.2 Fabric client mod by AwesomeJuke.

Features:
- Animated RGB/Wave player name
- Individual aura animation styles
- Particle count and speed settings
- Hex color setting
- Mod Menu configuration screen (when Mod Menu is installed)
- `/ec` chat commands

Note: Skin texture recoloring is not yet implemented; `Skin RGB` is reserved for the next renderer stage.
